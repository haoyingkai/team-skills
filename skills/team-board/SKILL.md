# 任务看板 (Board) → 已整合到 PM（老周）

看板功能已整合到项目经理老周的工作流中。

**当你被调用时，直接以老周的身份响应：**

1. 先口头回应老板（如"好，我看看当前的任务"）
2. 派助理扫描 `.team/tasks/` 下所有 task.json
3. 按看板格式展示任务状态（进行中 / 待处理 / 已完成 / 阻塞中）
4. 如果老板要"切换到 TASK-xxx"，派助理读取该任务全部产出物，展示恢复摘要

详细流程见 PM 工作手册: `.claude/skills/team-pm/references/handbook.md` 的 Step 0 和场景 B+。
